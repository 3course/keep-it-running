# Keep It Running — notes for Claude Code

Browser game, Phaser 3 + TypeScript + Vite. See README.md for the loop.

Rules of the codebase:
- `src/sim/` must never import Phaser. It's the whole game and it runs headless (`npm run sim`).
- Every balance number goes in `src/config.ts`. No magic numbers in `Game.ts` or scenes.
- New faults go in `src/data/faults.ts` only: symptom, diagnoses (exactly one `correct: true`), 2+ paths, each path 1–5 steps with minutes and cost. Cheap/slow DIY path first.
- `world` branch: the game is a Three.js world (`src/world3d/`), portrait 390×844, rendered at 1/3 resolution and upscaled nearest-neighbour. It drives `Game` through public methods only — never change `src/sim` or `config.ts` for presentation. The shed layout (0.5 m cells, objects with real heights) is data in `src/world/layout.ts`; world-only state (position in metres, what's carried, the bed, pallets) in `src/world/state.ts`; actions per object in `src/world/interactables.ts`; where each fault's fix happens and each step's one-thumb gesture in `src/world/fixes.ts` (gestures: `src/ui/gesture.ts`; a hands-on `Action` sets `gesture`); presentation numbers (speed, camera, ranges) in `src/world/worldConfig.ts`. All UI is DOM over the canvas (`src/ui/`). The Phaser versions are in history (`003eb00`).
- `src/world/save.ts` serialises every field of `Game`. A new field that isn't plain JSON (a Set, a class, a reference into another array) needs handling there too.
- After any change to config or faults: `npm run sim` and check competent stays roughly 10–20% margin and sloppy goes negative.
- The chores (clamps, the bed pile, the offcut bin, the compressor) sit behind `CONFIG.chores` (numbers in `CONFIG.chore`); `npm run sim -- nochores` must reproduce the economy as it was before them. `npm run sim -- seeds=20` for more seeds. See `claude/sim-chores.md`.
- Rare events and milestones sit behind `CONFIG.rareEvents` / `CONFIG.milestones`. With both off (`npm run sim -- baseline`) the sim must reproduce the economy exactly as it was before them. `?event=<id>` (council, bigJob, uteClip) forces one on day 1.
- Browser tests: `npm test` (Playwright, headless Chromium as a touch phone; first time on a machine: `npx playwright install chromium`). `tests/interactables.test.mjs` taps every object's action — a new `case` in `actionsFor` needs a test case there; `tests/touch.test.mjs` taps a visiting mate's labels (before/after 2pm, caps, wave-off and return); `tests/difficulty.test.mjs`, `tests/visitors.test.mjs`, `tests/upgrades.test.mjs`, `tests/overcommit.test.mjs` and `tests/rare-events.test.mjs` check the breakdown ramp, the lesson fire, the visitor rules, each upgrade, the board's-full warning, rare events and milestones on `Game` (no browser). `tests/chores.test.mjs` checks the chores on `Game` and by hand in the shed; `tests/fixes.test.mjs` does each fault fix by hand where it happens (real touch gestures, the beer fumble, the spray aim, the order card, the pickup to the ute); `tapLabel` performs any gesture a label opens. `tests/render-tiers.test.mjs` checks each renderer tier's internal resolution, `?res=`, and which tiers draw the extra detail (textures, sawdust, particles, lighting, outline). Browser tests start the game with `?seed=1`, so runs are repeatable. Run them after changing interactables, labels, the HUD, faults, fires or visitors.
- Designs (`src/designs/`): the shared format for what a job *is* — `Design` (types.ts: id, name, kind formwork/mdf/acrylic, customer, sheet size in mm, material, thickness, colour, `outer` + `inner` SVG path data with `cut`/`engrave`, the customer's note). Twelve in `catalogue.ts` (four per kind; lettering via the stroke font in `font.ts`). `designForJob(job)` picks one by hashing the order (all sheets of one order match) — the sim never knows. `path.ts` flattens path data and builds the toolpath (engrave, holes, outer last) with no DOM or Three.js, so anything later (after-hours tracing) should reuse it. Before: `sketch.ts` (pencil-on-graph-paper SVG) on the job card (`src/ui/jobCard.ts`) and the order card. During: `src/world3d/cutPath.ts` (the head follows the path, kerf ribbons). After: `piece.ts` extrudes the same path, `reveal.ts` plays the <3 s reveal (tap skips; low/bare tiers: no extra light, no particles, plain materials) and renders the gallery thumbnails; `w.made` lists today's pieces for "Made today" in the day summary. A new design must pass `tests/designs.test.mjs` (outline on its sheet, inner paths inside it).
- People (`src/people/`): no overtime any more — at 5 a mate (`friends.ts`: names, `[VOICE NOTES]`, topic stances, after-hours cut ideas; rotated, never the same two days running) is at the roller door: "Grab a beer" or "Head home". The night runs on a headless director (`night.ts`: turns, two replies + "Wind it up", "Another one?", ringing a mate from beer 2, the arc shop → life → deep, a big idea around beer 3, one argument a night rotated by `topicHistory`, an after-hours cut) over dialogue data in `dialogue/` (per-friend files, `bigIdeas.ts`, `topics.ts`, `group.ts`; templates are `TEMPLATE_KEYS`; tag lines with `expr`). `slur.ts` is the seeded drunk-spelling filter. View: `src/world3d/knockoff.ts` (crates by the fridge, now in the dock; two/three-shot; `figures.ts` faces and idles; dusk and the fridge light; `sfx.ts`), `tracing.ts` (the after-hours trace), `peopleDay.ts` (the part-timer `PEOPLE.partTimer`, customers at pickup, next-day gifts), `gratitude.ts` (gifts, keepsakes, the morning's cans and refund bag). Everything persists in `WorldState.people` (`src/people/state.ts`). The only `Game` hooks are `knockOffBeers`, `afterHoursSheet`, `refundCans` (the balance sim never calls them). Content checks: `tests/dialogue.test.mjs` (shape, no real brands, five nights per friend played through); in the shed: `tests/people.test.mjs`.
- Layout (`src/world/layoutPlan.ts`, `src/world3d/layoutEditor.ts`): twelve movable stations; the router, walls, doors and the switchboard are fixed. `problems()` checks a plan, `measure()` walks it with the player's pathfinding, `effectsOf()` turns that into `LayoutEffects` relative to the default plan (numbers in `CONFIG.layout`), so the default layout plays exactly as before. Game adds walking minutes only to walks it times itself (`g.worldWalks` is true in the shed). Saved in `w.layout`. `npm run sim -- layouts [seeds]` compares the presets and flags a spread over 8 points. `tests/layout.test.mjs`.
- Dennis (`src/sim/dennis.ts`, `CONFIG.dennis`): bets as plain data on `Game.dennis` (saved as is), his own seeded rolls, wins as revenue and costs/losses in `DayStats.bets`. The sim turns him off unless run with `-- dennis`, so the default report is unchanged; `npm run sim -- dennis [seeds]` (add `only=<kind>` to price one bet) checks yes-to-all beats no-to-all by 2+ points but its worst seed loses to no's best. View: `src/world3d/dennisView.ts`; lines `src/people/lines/dennis.ts`; he's also a knock-off friend (`occasional`, `lightweight`). `tests/dennis.test.mjs`.
- The rare late one (`src/people/dialogue/lsg.ts`, `src/world3d/lsg.ts`): group nights only, after beer 3, never the first night, once a week; `knockoff.forceLsg` for tests.
- Commit after each system or balance pass.
